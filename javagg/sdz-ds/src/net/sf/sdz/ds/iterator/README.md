# Iterator

Just the `Iterator<E>` design-pattern interface (`hasNext()`/`next()`), kept in its own package
so it doesn't collide with `java.util.Iterator`. See
[`net.sf.sdz.ds.lists`](../lists/README.md) for what implements it (`SingleLinkedList`) and
why it's separate from `LinkedList.nextElement()`.
