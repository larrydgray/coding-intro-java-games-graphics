# Simple 3D Graphics using Java Swing

Isometric/oblique 3D surface rendering: project 3D points onto a 2D plane and draw a wireframe
terrain grid. No hidden-line removal, filling, texture mapping, or true rotation — just the
projection math and a random, smoothed height field.

## Iso3D

`Iso3D` holds `Point2D`/`Point3D` inner classes and `transform3D(Point3D)`, which projects a
3D point down to 2D using one of three modes (`LEFT_ISO`, `CENTER_ISO`, `RIGHT_ISO`) selected
by `setTransformMode`/`mode`:

```java
case LEFT_ISO:   return new Point2D(x + z, (int) ((-y + z) * ySkew));
case CENTER_ISO: return new Point2D(x + z, (int) ((-y + z - x) * ySkew));
case RIGHT_ISO:  return new Point2D(x - z, (int) ((-y + z) * ySkew));
```

The same transform works for full 3D polyhedra too (not just heightmaps) — e.g. for voxel-style
games.

## IsoPanel

A `JPanel` with an inner `Surface3D` class holding a `xGridSize` × `yGridSize` grid of random
elevations. Terrain is generated by scattering `nRandomHeights` random peaks, then smoothing the
whole grid by averaging each point with its 8 neighbors, done twice. `paintComponent` walks the
grid and draws wireframe lines between adjacent points (projected through `Iso3D`), offset by a
pannable `originX`/`originY` and scaled by `ySkew`.

## IsoTest

The frame and controls: buttons to switch projection mode (left/center/right), pan
(left/right/up/down), adjust vertical skew (`Y+`/`Y-` on the panel's own `ySkew`, `2D Y+`/`2D Y-`
on `Iso3D`'s), and zoom in/out by shrinking/growing the grid square size.

## Where to take this further

Ideas the original article calls out: filled polygons with a painter's-algorithm hidden-line
removal, elevation-based coloring (blue water → green land → white peaks), loading real terrain
data or a fractal generator, 90-degree (or full trig-based) rotation, and persisting the surface
to disk — see [`sdz-data`](../../../../../../sdz-data) for file I/O examples to do that with.
